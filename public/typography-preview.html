The exact match to your reference image

The font in your reference image is labeled "Chico Mato" — a commercial script/blackletter hybrid typeface (the genuine "Chicano lettering" genre lives almost entirely in paid type foundries, not Google Fonts). I can't embed it here: I don't have a license for it, and per your instructions I won't download or bundle an unlicensed font file.

If you want a pixel-match to that reference specifically, you'd need to purchase a license for Chico Mato (or a similar Chicano tattoo-lettering font pack) yourself. Once you have the licensed .woff2/.woff files, send them over — the site already has a drop-in slot for exactly this (src/assets/fonts/, documented in that folder's README) and I'll wire it in the same way, no other code changes needed.
